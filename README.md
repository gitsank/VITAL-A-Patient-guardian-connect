# VITAL — Digital Patient Tracking System

VITAL is a web application project focused on digitizing and centralizing patient-status records. It is intended to make patient information easier to organize and review through a single interface.

## Project Overview

The project explores how a web-based interface can support patient tracking and information management. Its goal is to replace fragmented status records with a more accessible digital workflow.

## Core Goals

- **Centralized records:** Bring patient status information into one application.
- **Digital workflow:** Support the transition from manual or scattered records to structured web-based information.
- **Clear interface:** Present information through a component-based user interface.
- **Maintainable frontend:** Use a modern TypeScript and React development stack.

## Technology Stack

- **React** — component-based UI development
- **TypeScript** — typed application code
- **Vite** — development server and build tooling
- **Tailwind CSS** — utility-first styling
- **shadcn/ui** — reusable interface components

## Run Locally

### Prerequisites

Install a current version of Node.js and npm.

### Setup

```bash
git clone https://github.com/gitsank/VITAL-A-Patient-guardian-connect.git
cd VITAL-A-Patient-guardian-connect
npm install
npm run dev
```

Use the local URL printed by Vite to open the application.

## Development

You can work on the project using your preferred IDE or GitHub Codespaces. Changes pushed to the repository are also reflected in the connected Lovable project.

## Project Focus

VITAL demonstrates frontend application development, TypeScript-based UI implementation, and the digitization of patient-status information.

> **Scope note:** This repository describes a project prototype. Do not use it as a clinical system or store real patient information unless appropriate security, privacy, access-control, and compliance measures have been implemented and validated.
